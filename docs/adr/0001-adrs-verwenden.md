# 0001: Grundentscheidungen als ADRs festhalten

Datum: 2026-11-06 · Status: Angenommen

## Kontext

Claude arbeitet weitgehend autonom und in vielen Sessions. Ohne schriftliche Begründung werden Entscheidungen vergessen oder unbemerkt gekippt.

## Entscheidung

Jede Grundentscheidung bekommt ein kurzes ADR in `docs/adr/`. Wer eine Grundentscheidung ändern will, schreibt ein neues ADR und markiert das alte als ersetzt.

## Folgen

Die Liste in `docs/adr/README.md` ist das Inhaltsverzeichnis der Architektur.
